Los **Knowledge Graph Embeddings** asignan representaciones vectoriales a entidades y relaciones de un grafo de conocimiento. El objetivo consiste en capturar regularidades estructurales para tareas como la predicción de enlaces.

## De triples a vectores

Una base de conocimiento puede representarse mediante triples `(sujeto, relación, objeto)`. Distintos modelos definen funciones de puntuación para estimar la plausibilidad de cada triple.
